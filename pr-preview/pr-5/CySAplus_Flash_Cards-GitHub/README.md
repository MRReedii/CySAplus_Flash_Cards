# CySA+ Flashcards & Quiz

Open `index.html` in a modern web browser. No install, server, or external dependency is required.

## Use

- Use **Previous**, **Flip**, **Next**, and **Shuffle** in flashcard mode.
- Click anywhere on the flashcard (away from a control) to flip it.
- Hover over the shield (**🛡**) beside the title to reveal the hidden-theme/quiz hint. Select it to activate the hidden cyberpunk theme and start quiz mode; quiz details are not shown in the normal flashcard viewΩ- In quiz mode, select an answer to receive instant feedback and then advance.
-  The digital readout awards **100 points** for every correct answer and maintains a running **incorrect-answer** total.
- Use **Flashcards** from quiz mode to return to the original normal-theme flashcard experience.
