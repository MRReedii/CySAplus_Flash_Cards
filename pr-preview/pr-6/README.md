# 🛡 CySA+ Flashcards

A lightweight, browser-based flashcard deck for CompTIA CySA+ study — built by students, for students.

---

### How this started

We're in the middle of a three-month cybersecurity program (Per Scholas) with about 30 people, working toward CySA+ and Splunk certifications while balancing real work. Somewhere along the way, people started making digital flashcard sets — PDFs, question banks, the usual.

One of the students in our Standup group shared a solid PDF set. I turned those questions into this web page so we could study them more easily. Now the two of us are collaborating to turn this into a small hub where members of the cohort can share and study from each other's question sets.

### What this is right now

- A clean, interactive flashcard interface (flip cards, keyboard navigation, shuffle)
- 50 CySA+ practice questions covering network security, vulnerability management, incident response, threat intelligence, and more
- Hosted on GitHub Pages so anyone in the cohort can open it instantly

### Where we're headed

- Pull in more question sets from other students in the class
- Make this a shared space for the cohort's study materials
- Password-protect some decks, leave others public
- Keep it simple and useful

This is an independent side project between the two of us who started it. No official affiliation — just students helping each other get through the material.
